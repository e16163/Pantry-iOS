# Ingredient photo prompts

Each prompt below makes **one grid sheet of ingredient photos**. There are 13 sheets covering all 200 ingredients in the app.

1. Paste each prompt into ChatGPT image generation.
2. Check the ingredients appear **in the listed order**, left to right, top to bottom. If one is wrong or missing, regenerate that sheet.
3. Save each image with the file name in its heading, e.g. `ingredient-sheet-01.png`, all in one folder.
4. Give the folder to Claude, or run: `python3 tools/slice-ingredient-sheets.py <folder>`. It cuts each sheet into one image per ingredient and adds them to `Assets.xcassets/Ingredients`.

Ingredients without a photo show their category photo instead, so partial sets are fine.
